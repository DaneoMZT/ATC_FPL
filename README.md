# ATCFPL — Sprint 2 y Retrospectiva

Este repositorio contiene la documentación correspondiente al **Sprint 2 del proyecto ATCFPL**, realizado como parte de la materia **Proyecto VII** de la Universidad de Guadalajara.

## Objetivo del Sprint 2

Durante este Sprint el trabajo se enfocó principalmente en el **diseño e implementación inicial de la base de datos** y en el **desarrollo de la primera estructura de la interfaz web** de ATCFPL.

El objetivo fue establecer una base funcional que permita continuar en los siguientes Sprints con la captura de planes de vuelo, consultas de información y posteriormente la implementación de validaciones básicas.

## Actividades realizadas

Durante el Sprint 2 se realizaron las siguientes actividades:

- Creación y organización inicial de la base de datos `atc_database` en MongoDB.
- Importación y pruebas con información aeronáutica.
- Desarrollo de la estructura inicial de la aplicación con Vue.js y Vite.
- Creación de componentes para la navegación e interfaz.
- Pruebas iniciales de integración entre frontend, backend y base de datos.
- Implementación inicial del backend utilizando Node.js y Express.
- Pruebas de consultas y rutas como parte del avance del proyecto.

## Resultados del Sprint

Al finalizar el Sprint 2 se obtuvo una primera estructura funcional de ATCFPL. La aplicación cuenta con una base de datos inicial y una interfaz web que servirán como base para continuar incorporando nuevas funcionalidades.

El Sprint 2 fue planeado con un total de **13 Story Points**, relacionados principalmente con el desarrollo inicial de la base de datos y el diseño de la interfaz.

## Retrospectiva

La retrospectiva permitió analizar los resultados obtenidos durante el Sprint, así como identificar los problemas encontrados y las oportunidades de mejora para las siguientes etapas.

Uno de los principales resultados fue comprobar la integración entre **Vue.js, Node.js/Express y MongoDB**, permitiendo verificar la comunicación entre el frontend, backend y la base de datos.

Durante el desarrollo también se presentaron dificultades relacionadas con la estructura de componentes de Vue, la ejecución de Vite, la organización de archivos y la configuración del backend.

A partir de esta experiencia se identificó la importancia de realizar cambios de manera gradual, probar cada modificación antes de continuar y mantener una mejor documentación de las configuraciones y comandos utilizados.

## Modificaciones para el siguiente Sprint

Para el **Sprint 3** se continuará con la planeación establecida para el proyecto, enfocándose principalmente en:

- Captura de información de planes de vuelo.
- Acceso básico a la información.
- Primeras consultas desde la aplicación.
- Continuación del desarrollo de la API.
- Integración entre Vue.js, Node.js/Express y MongoDB.

Los avances realizados anticipadamente durante el Sprint 2 se conservarán como base para las siguientes etapas del proyecto.
