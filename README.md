# ATCFPL — Sprint 1

Este repositorio contiene la documentación correspondiente al **Sprint 1 del proyecto ATCFPL**, realizado como parte de la materia **Proyecto VII** de la Universidad de Guadalajara.

## Objetivo del Sprint 1

El objetivo principal de este Sprint fue establecer las bases para comenzar el desarrollo de ATCFPL, definiendo los requerimientos iniciales del proyecto, seleccionando las tecnologías necesarias y preparando el entorno de trabajo.

Esta primera etapa permitió organizar el proyecto antes de comenzar con el desarrollo de las funciones principales de la aplicación.

## Actividades realizadas

Durante el Sprint 1 se trabajó principalmente en:

- Definición de los requerimientos iniciales del proyecto.
- Identificación del problema que busca resolver ATCFPL.
- Definición del alcance inicial y del Producto Mínimo Viable (MVP).
- Selección de las tecnologías para el desarrollo.
- Preparación y configuración del entorno de trabajo.
- Definición inicial de la arquitectura de la aplicación.
- Primeras pruebas de comunicación entre la aplicación web y la base de datos.
- Organización inicial del Product Backlog.
- Planeación de los siguientes Sprints.

## Tecnologías seleccionadas

Para el desarrollo inicial del proyecto se consideraron las siguientes tecnologías:

- **Vue.js** para el desarrollo del frontend.
- **MongoDB** como sistema de base de datos.
- **JSON/BSON** para el manejo e intercambio de información.
- **HTTP** para la comunicación entre los componentes de la aplicación.
- **mongosh** como herramienta para realizar pruebas y consultas en MongoDB.

Durante la planeación inicial se contempló PHP para el backend. Esta decisión fue revisada posteriormente durante el desarrollo del proyecto.

## Resultados del Sprint

Al finalizar el Sprint 1 se obtuvo una definición más clara de la estructura y alcance de ATCFPL.

Se establecieron los requerimientos iniciales, las tecnologías principales y la arquitectura sobre la cual se continuaría trabajando durante los siguientes Sprints.

El Sprint 1 fue planeado con un total de **13 Story Points**, correspondientes principalmente a la definición de requerimientos, selección de tecnologías, configuración del entorno y primeras pruebas.

## Retrospectiva

La revisión de este primer Sprint permitió identificar la importancia de establecer una estructura clara antes de comenzar con el desarrollo de funciones más complejas.

También permitió reconocer que algunas decisiones técnicas podrían necesitar ajustes conforme avanzaran las pruebas y se adquiriera mayor experiencia con las herramientas seleccionadas.

Como resultado, se decidió mantener una metodología de desarrollo incremental, realizando pruebas durante cada etapa y dejando abierta la posibilidad de adaptar las tecnologías cuando fuera necesario, sin modificar el objetivo principal del proyecto.

## Preparación para el Sprint 2

Con las bases establecidas durante el Sprint 1, la siguiente etapa se enfocaría principalmente en:

- Diseñar e implementar la estructura inicial de la base de datos.
- Comenzar a organizar la información aeronáutica.
- Desarrollar la primera estructura visual de la aplicación.
- Preparar la interfaz para las funciones que se incorporarían posteriormente.
- Continuar realizando pruebas de integración entre los componentes del sistema.

De esta manera, el Sprint 1 funcionó como punto de partida para comenzar el desarrollo técnico de ATCFPL durante el Sprint 2.
