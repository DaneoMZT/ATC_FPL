# ✈️ Bienvenido a ATCFPL

**ATCFPL** es un proyecto académico enfocado en el desarrollo de una plataforma web para la gestión y consulta de información relacionada con planes de vuelo.

El proyecto se desarrolla de manera incremental mediante **Sprints**, incorporando progresivamente la base de datos, interfaz web, servicios de consulta y funcionalidades para el manejo de planes de vuelo.

## 📂 Contenido del repositorio

- `sprint-1` — Documentación del primer Sprint.
- `sprint-2` — Documentación y retrospectiva del segundo Sprint.
- `atcfpl_code` — Código fuente del proyecto.

## 🛠️ Tecnologías

**Vue.js · Vite · Node.js · Express · MongoDB**

> ATCFPL es un prototipo académico en desarrollo y no está destinado para uso en sistemas ATC operativos.
